# Power BI Profit Analysis Dashboard

## 📊 Project Overview

This project is an interactive **Profit Analysis Dashboard built using Microsoft Power BI** to analyze profitability across different business dimensions.

The dashboard provides insights into profit performance by **Year, Region, Category, Sub-Category, Segment, and Ship Mode** and uses DAX measures to perform comparative and cumulative analysis.

## 🎯 Business Objective

The objective of this project is to:

- Analyze overall profit performance
- Identify the most and least profitable sub-categories
- Compare profit across regions and categories
- Analyze yearly profit trends
- Understand profitability by customer segment
- Analyze profit by shipping mode
- Identify areas contributing positively or negatively to overall profit

## 🛠️ Tools & Technologies

## 📌 Key Dashboard Features

### Profit Analysis Report

The dashboard includes:

- Total Profit
- Total Orders
- Total Quantity
- Profit by Region
- Profit by Category
- Profit by Sub-Category
- Profit by Year
- Profit by Segment
- Profit by Ship Mode
- Sales and Profit comparison
- Interactive Category and Year slicers
- Region filtering

### Cumulative Analysis Report

The project also includes cumulative analysis using DAX, including:

- Running Total Sales by Sub-Category
- Running Total Sales by Year
- Year-over-Year analysis
- Previous Year Sales comparison
- Period comparison
- Cumulative sales analysis

## 🧮 DAX Analysis

DAX measures were created for:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Previous Year Sales
- Year-over-Year %
- Running Total
- Period comparisons
- Cumulative analysis

Functions and concepts used include:

- CALCULATE
- FILTER
- ALL
- ALLSELECTED
- RANKX
- SUMX
- DIVIDE
- DATEADD
- SAMEPERIODLASTYEAR
- Time Intelligence

## 🏗️ Data Model

The project uses a structured data model with:

- SalesData fact table
- Date table
- Products dimension
- Customers dimension
- Regions dimension
- Address dimension
- Segment dimension
- Ship Mode dimension
- Returns table

A star-schema-based approach was used to organize the model and support efficient reporting and analysis.
